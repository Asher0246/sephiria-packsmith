# Sephiria Packsmith

一个在本机浏览器中运行的《Sephiria》背包自动排布工具。目录由 Sephiria Wiki 与游戏文本生成，当前包含 268 种神器与 61 种石板；用户录入本局已获取物品后，可以为每个实例指定固定位置、最低/固定等级、固定旋转和优先权重，由 OR-Tools CP-SAT 搜索最优布局。

## 启动

环境要求：Windows 10/11 与 Python 3.12。首次使用，在 PowerShell 中运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\setup.ps1
```

依赖安装完成后，双击 `启动求解器.bat`。服务只监听 `127.0.0.1`，会使用随机访问令牌打开默认浏览器；关闭控制台窗口即可停止服务。

开发时可运行：

```powershell
.\runtime\Scripts\python.exe -m app.server --port 0
.\runtime\Scripts\python.exe -m pytest tests -v
```

更新 Wiki 目录需要 Node.js 20 或更高版本，并需要联网运行：

```powershell
.\runtime\Scripts\python.exe .\tools\scrape_wiki.py
```

生成后的目录随项目保存，普通启动与求解不需要联网，也不需要 Node.js。

## 使用

1. 在左侧检索神器或石板，点击条目添加本局实际拥有的每个实例；同类物品可以重复添加。
2. 在“当前构筑”中按需录入每件神器本局获得的附魔等级，并设置固定位置、最低等级/固定等级与优先权重，或石板固定旋转。留空表示交由求解器决定。
3. 和谐之晶、多用途腰带、巨型望远镜、白纸和北向的金色针可按实例打开“优先特殊效果”；金色针还需手动选择应放在其正上方的目标神器。
4. 输入当前背包格数、求解线程和时限，点击“自动求解”。线程默认由 OR-Tools 按本机 CPU 自动选择，也可固定为 8、16 或 32；背包固定为 6 列，最后一行可以不足 6 格，所有录入物品都必须被放入背包且不能重叠。
5. 棋盘显示每个格子的石板加成、解锁状态、神器最终等级和石板旋转；下方表格列出神器贡献。
6. 当前构筑中至少有两块石板时，可点击“合成石板”，分别选择两块源石板参与合成时的方向。工具会按游戏规则生成一块自定义石板，并在当前构筑中用它替换两块源石板；此操作只修改工具内的构筑，不会写回游戏。

状态含义：

- `已证明最优`：已启用的加权特殊效果、主目标（权重 × 生效等级）、次目标（生效等级总和）、副作用惩罚与空闲格加成均已完成最优性证明。每项特殊效果先按理论上限归一化到 0～1000，再乘对应神器的优先权重；它先于所有等级目标参与比较，随后依次比较主目标、次目标、副作用惩罚与空闲格加成。只要存在能达成特殊效果的排布，求解器就会优先达成它。
- `已找到可行排布`：时限内找到了合法方案，但尚未证明最优；界面会显示当前解与上界的差距。
- `没有可行排布`：固定位置、最低等级或背包容量等硬约束相互冲突。

构筑会自动保存在浏览器本地。已证明最优与不可行的求解结果会在本机缓存（Windows 位于 `%LOCALAPPDATA%\SephiriaPacksmith`），重复提交相同构筑时立即返回；求解器代码或目录数据变化后缓存自动失效。

## 从游戏读取

可选的 Windows 插件可以直接读取单机游戏当前背包，并将已确认的求解结果自动应用到游戏。安装前先关闭或稍后重启游戏，然后运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\game_plugin\install.ps1
```

进入一局游戏后启动求解器，点击顶部“读取游戏”。插件通过本机命名管道发送神器、石板、背包格数和局内临时等级。游戏内合成的自定义石板会同时读取名称、当前方向、可旋转性、效果范围与限定条件，并作为动态石板类型加入当前构筑。求解完成后可点击“应用到游戏”；即使读取后手动调整过物品位置或石板方向，插件也会以游戏中的当前排布为起点直接应用目标排布。应用时仍会校验游戏版本、背包格数和完整物品实例集合，在 Unity 主线程调用游戏自身的交换和点击接口，并在结束后复核排布。插件不会直接改写背包矩阵或物品坐标，失败时会尽量恢复应用前的排布。卸载命令：

```powershell
powershell -ExecutionPolicy Bypass -File .\game_plugin\uninstall.ps1
```

## 数据与规则

- 神器目录由 `tools/scrape_wiki.py` 从 `https://www.sephiria.wiki/artifact` 生成到 `assets/wiki_artifacts.json`，使用 Wiki 的英文稳定 ID、图片、效果档位上限、套装与排布约束。界面只展示求解所需的短信息，不提供背景描述或完整效果正文。
- 石板目录从 `https://www.sephiria.wiki/large` 当前引用的 Next.js 数据模块生成到 `assets/wiki_tablets.json.gz`；更新器直接执行隔离后的官方规则模块，预计算所有支持背包尺寸的旋转、等级增减与解锁效果。
- 神器启用条件支持边缘、内侧、最上行、最下行、左右两端、左右留空和两侧神器；被石板解锁的格子可绕过启用位置条件。
- 所有神器的基础等级默认为 0；效果序列的第一档对应 0 级，因此 `a/b/c` 三档的等级上限为 2。局内附魔等级按神器实例录入，最终等级按下述石板加成与倍率顺序计算，并在效果档位上限处截断。负等级会保留并使神器不生效，但不会令排布不可行；0 级神器仍可生效。固定效果神器可能没有可提升等级，但仍会完整显示在目录中。
- 自定义石板支持游戏的整数等级增减、`X` 禁用、`IGNORECRITERIA` 绕过神器位置条件和 `MUL/n` 倍率；等级计算顺序为 `(局内附魔等级 + 石板净加成) × 倍率`，然后按神器等级上限截断。`ITEM`、`CHARM` 与 `PLACED` 限定条件会根据最终排布决定石板是否生效。
- 游戏合成规则按旋转后的两块源石板合并效果范围；两块非空限定条件必须完全相同，只存在一块非空限定时继承该限定，且仅当两块源石板都可旋转时结果才可旋转。
