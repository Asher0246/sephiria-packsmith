Sephiria Packsmith 背包自动排布求解器（Windows x64）

一、直接使用求解器
1. 将整个 ZIP 解压到普通文件夹，不要直接在压缩包内运行。
2. 双击“启动求解器.bat”。
3. 默认浏览器会自动打开本地页面。关闭命令行窗口即可停止求解器。

求解器只监听 127.0.0.1，并使用每次启动随机生成的访问令牌。
便携 Python 和 OR-Tools 已包含在包内，无需安装 Python，也无需联网。

二、从游戏直接读取背包（可选）
1. 先关闭 Sephiria。
2. 打开 game_plugin 文件夹，双击“安装插件.bat”。脚本会自动查找 Steam 库。
3. 启动游戏并进入一局，再启动求解器，点击顶部“读取游戏”。

游戏内已经合成的自定义石板会连同效果范围、限定条件和可旋转性一起读取。
也可以在工具的“当前构筑”中点击“合成石板”，选择两块已有石板及合成方向；
工具会用合成结果替换两块源石板，但不会把修改写回游戏。

插件只读取本地玩家背包，并通过本机命名管道发送快照；不会写入游戏内存，
也不会调用游戏命令。卸载时先关闭游戏，再双击“卸载插件.bat”。卸载脚本只
移除 SephiriaInventoryBridge.dll，会保留可能被其他插件使用的 BepInEx。

如果 Steam 游戏目录无法自动找到，可在 PowerShell 中手动运行：
powershell -ExecutionPolicy Bypass -File .\game_plugin\install.ps1 -GameDir "你的Sephiria目录"

三、系统要求
- Windows 10/11 x64
- Steam 版 Sephiria
- 浏览器：Edge、Chrome 或 Firefox 的较新版本

本包包含 BepInEx 5.4.23.5。第三方组件的许可证保留在 runtime 与
THIRD_PARTY_LICENSES 目录中。
